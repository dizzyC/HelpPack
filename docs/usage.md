# Using HelpPack English Edition

1. **Create Support Bundle**: choose a problem and describe symptoms, recent changes and actions tried. Your own words are never translated.
2. Add up to five PNG/JPG/JPEG screenshots. **Crop / Cover Selected Screenshot** edits a copy, not the original. Cover sensitive areas with opaque black and inspect the full image.
3. Collect system information, review privacy and choose retained screenshots.
4. Edit the report or uncheck system fields and **Update Preview**. Regeneration replaces manual edits; preserve them first. The concise summary only uses the current preview.
5. Export Markdown or ZIP. Review the report and screenshots yourself before sharing.

## Diagnostics

Choose a problem and **Run Check**. Findings include status, severity, confidence and evidence. Select a finding to see its full scrollable text. Failed, inaccessible or unsupported checks do not establish a fault.

**Review Selected Repair** explains the target, impact, permissions, internet use, restart needs and recovery limits. Approve only actions you understand. Store data reset requires typing **RESET**; its internal compatibility value is retained. HelpPack never restarts Windows automatically.

## Repair plans

After Diagnostics, open **Review Repair Plan**. Read evidence and impact, select actions and confirm. Actions that can interrupt a network, app or service require separate confirmation. **Stop Scheduling Further Actions** does not kill an active Windows transaction. Review the before/after evidence and related recheck, then decide whether the issue is resolved. Use **Restore Previous HelpPack Changes** for eligible backups; conflicting current settings are never overwritten. See the [action and recovery matrix](repair-plan-verification.md).

## Targeted check details

- **Symptoms**: local English/Chinese keyword routing, not an AI diagnosis.
- **Network**: standard-port HTTPS URL without credentials/query/fragment; optional DNS of your choice. Compare adapter, gateway, DNS, proxy/direct HTTPS and target response. CDN differences are not proof of DNS interference.
- **Software**: choose a running program or local EXE; it is not executed. Scenarios: Won't start, Crashes, Not responding, Installation fails. Dependencies/signatures do not prove health.
- **Storage**: bounded scan of your folder. Review and quarantine one cache candidate. Rescan to restore it, without overwriting existing files. Same-partition quarantine does not free space.
- **Devices**: read-only audio, Bluetooth and printer checks. Playback and one-page printing require separate user actions. Printing confirmation warns about paper/toner and virtual-printer dialogs.
- **History**: compare matching checks and assign Resolved / Unresolved / Later yourself. Improvement is not automatically resolution.
- **Timeline**: bounded recent logs; timing is a clue, not causation.
- **Monitoring**: two-second resource samples. **A Problem Just Happened** retains preceding/following samples. Stop or exit to end monitoring; incomplete incident segments stay marked incomplete.
