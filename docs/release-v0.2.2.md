# HelpPack v0.2.2

Windows 单文件应用，无需安装 Python。下载 `HelpPack.exe`，校验值见 `HelpPack.exe.sha256`。

## 本次变化

- 本机诊断结果增加可滚动、可选择复制的完整内容区域，修正长文字显示不全。
- 商店检查区分查询失败、当前用户未注册和策略禁用；已注册包恢复使用实际清单，不硬编码包版本，不盲目重置数据或批量注册系统应用。
- 加入 TLS 1.2/1.3 配置只读检查及商店 0x80131500 操作指引；按 Windows 支持版本区分，不自动修改安全设置。
- 新增逐项确认修复框架、管理员辅助模式、过期/篡改/重放保护、本机备份和脱敏执行记录。
- 新增 DNS 缓存、指定物理 DHCP 接口、Store、白名单服务及 Windows Update 单项驱动相关流程；高风险需二次确认，永不自动重启。
- 保留求助包、报告预览编辑、规则脱敏、Markdown/ZIP/manifest 导出。

## 验证结果和重要限制

- 69 项 pytest、Ruff、报告/ZIP 内容与哈希校验通过。
- 本机 21 项 L0 检查完成，已检查的启动项/代理前后快照一致，未执行修复。
- 新 EXE 离屏启动通过，真实窗口首页→商店只读诊断→结果/TLS 详情已观察；长文本、缩放和取消另有源码 Qt 自动检查。
- **新增商店、网络、服务、驱动修改尚未在可还原 Windows 环境中真实验收；UAC 成功/取消和修改后恢复未实测。自动化/模拟通过不代表真实修复通过。**
- 本版本经用户明确确认上传，不应视为全部扩展计划已完成。建议优先使用只读诊断与求助包，不在重要电脑上试用未验收修复。
- Windows 10 不强行开启不支持的 TLS 1.3；未注册 Store 且机器级包存在性未知时只提供人工步骤。配置正常不代表商店已经能加载。
- 厂商驱动来源仅提供官方页面，不自动下载厂商安装包；本地 INF 自动安装受安全限制拒绝执行。无可靠证据时不提供全局网络重置或 DISM/SFC 自动修复。
- 快照仅本机保存；部分回滚尚无完整界面。驱动备份只是尽力恢复材料，不承诺可还原。
- EXE 未代码签名，可能显示 SmartScreen 提示。截图内容不做 OCR，导出前需自行检查隐私。

完整状态见 [验证记录](https://github.com/dizzyC/HelpPack/blob/v0.2.2/docs/verification-v0.2.2.md)。本次仅上传 EXE 与 SHA-256，不上传本机报告、验证截图或用户附件。
